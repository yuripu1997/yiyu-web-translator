# 产品命名候选

当前工作名：**译屿**（YIYU）

| 名称 | 气质 | 一句话 |
|---|---|---|
| **译屿** | 安静、独特、有画面 | 语言之间的岛屿，让译文自然靠岸 |
| **页语** | 直接、好记 | 每一页，都听得懂你的语言 |
| **译岸** | 温和、可信 | 两种语言，在同一页靠岸 |
| **语间** | 克制、设计感 | 在语言之间，留出呼吸 |
| **双页** | 功能直白 | 原文与译文，一页并置 |
| **澜译** | 有品牌感 | 让文字像水一样流过去 |

推荐使用「译屿」：两个字都常见、易读，组合不撞现有翻译产品；英文 `YIYU` 也适合做图标和域名前缀。

如果后续要换名，只需修改 `src/shared/brand.js`，页面标题和设置页品牌信息会跟随；快捷键、存储键和 provider 配置不受影响。
