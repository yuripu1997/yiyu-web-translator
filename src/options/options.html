腾讯云文本翻译自 2026-10-01 起停止发放新的免费资源包；已有资源包按有效期使用，超出后按量计费。 获取 SecretId / SecretKey ↗ · 开通 TMT ↗

 

DeepL API Free 官方页面提到每月约 50 万字符免费（计划状态有调整，以注册页为准）。 申请 DeepL API Key ↗

Azure Translator F0 免费层约 200 万字符/月；需要 Azure 账号和信用卡。 创建 Translator 资源 ↗

MyMemory 无需 API Key，匿名约 5,000 字符/天；它需要明确源语言，源语言选「自动检测」时会按英语处理。 API 文档 ↗

可本地 Docker 部署，完全免费；公共实例可能限速或要求 API Key。 部署文档 ↗ · 公共实例 ↗

填写任意兼容 OpenAI 的 Base URL、API Key，再点击「获取模型」从 /models 拉取模型列表；也可以直接手填模型名。参数保持默认即可。

所有密钥只保存在浏览器本地（chrome.storage.local），不会上传到任何第三方服务器；网页内容只会发送到你选择的翻译服务。
